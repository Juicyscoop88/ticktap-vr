# TickTap VR

A hand-tracked time-manipulation puzzle game for Meta Quest and Meta VR Glasses.

**Time moves when you move.** Hold your hand still and the world freezes. Move through space to navigate obstacles and reach the goal before time runs out.

Built for the [Meta VR Start Developer Competition 2026](https://developers.meta.com/blog/meta-connect-2026-vr-start-developer-competition/).
